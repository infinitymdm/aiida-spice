# aiida-spice

AiiDA plugin for SPICE circuit simulation.

This plugin brings AiiDA's orchestration and provenance features to device-level electrical
simulation, with the aim of supporting a variety of FOSS and commercial simulator engines.

### Supported Simulators

- [ngspice](https://ngspice.sourceforge.io/)

## Installation

```
pip install git+https://github.com/infinitymdm/aiida-spice.git
```
